# Oidua

Oidua 可检测现场录音的 BPM，并深度分析所选歌曲。即时呈现调号、歌曲结构、速度、响度，以及人声、鼓和贝斯的动态。

相比手动打拍子，它的 BPM 识别更加准确，尤其适合快节奏歌曲。


### 主要特性

- 实时 BPM 检测：实时测量现场录音的速度（节奏）。  
- 深度音轨分析：查看歌曲的调号、结构、速度、响度，以及人声、鼓和贝斯的音域分布和动态。  
- 内置音频播放：直接在应用内播放录音和歌曲。  
- 实时图表指针：在分析图表上实时跟随播放进度。  
- 拖拽定位进度：在图表上拖动指针，快速跳转至歌曲任意段落。  
- 支持深色模式：低光环境下，提供舒适的视觉体验。  

注：不支持受 DRM 保护的歌曲（如 Apple Music 流媒体音乐）。
